Chapter 1 - How a Computer Works

Chapter Summary

1. What is a Computer?

A computer is an electronic machine that helps us work fast and accurately.

2. IPO Cycle

IPO means Input → Process → Output.

  • Input: Data entered by keyboard/mouse
  • Process: CPU works on data
  • Output: Result shown on monitor

3. Hardware

Hardware means physical parts of computer that can be touched like monitor, keyboard, mouse, CPU.

4. Software

Software means programs that run computer like Paint, MS Word, etc.

Remember

Computer works very fast and helps us in study.
